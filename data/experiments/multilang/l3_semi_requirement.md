# 测试需求（工程师交接版，半精确）

对 REST 专辑服务做回归测试，以下行为契约需逐条验证：

1. 专辑名称长度上限为 128 字符（按字符数计），超长返回 400；新增（Create）
   与编辑（Update）接口的长度规则保持一致。
2. 查询不存在的资源返回 404（NotFound），不应返回 500。
3. 列表分页：总页数 = ceil(total/per_page)（向上取整），末页应能取到余数条目；
   page 超出总页数时的钳制行为与 page_count 一致。
4. 登录 JWT 默认有效期为 72 小时（exp-iat ≈ 259200s），过期前使用不应 401。
