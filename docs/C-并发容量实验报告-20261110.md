## 4. 结论三行式（论文"局限与容量边界"节直接引用）

1. **容器层**：一任务一容器模型在 12 核单机 5 路并发下伸缩平坦（冷链路 +44%），容器层不是系统容量瓶颈；
2. **LLM 层**：容量完全由 LLM 端点决定——云端（DeepSeek）3 路并发延迟不变、5 路端到端单任务墙钟无系统性增长；本地（4GB 卡 ollama）单路即受生成速度制约（快窗 12 tok/s / 劣化窗 0.5 tok/s 双峰态），劣化态 3 路并发即服务崩溃——**本地档只适合单任务串行，且需 skill 级超时保护**（gen 300s 实测必超时，本地档完整链路待 FA+KV 提档后复测）；
3. **相互干扰**：5 路并发下无 SQLite 锁冲突、无容器资源挤兑实锤；LLM 劣化/崩溃是唯一观察到的并发失效点。
