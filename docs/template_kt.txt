| （1）选题依据（目的、意义、研究现状、可行性）                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                     |
| Packing问题是关于空间的利用的一类典型的NP难度问题，研究一组物体在有限区域内互不重叠的优良布局。在工程设计领域中的许多实际问题，例如码头货物的装运、板材的切割、超大规模集成电路(VLSI)布局设计等，这些问题都可以形式化为一个矩形Packing问题，因此寻找这类问题的快速解法，具有重大的实际意义。同时，这类问题又是一个典型的NP-难问题，涉及到计算机科学理论的核心问题，因此具有深刻的理论价值。         |
|                                                                                                                                                                                                                                                                                                                                                                                                     |
| 在国内，对Packing问题的研究比较少，工作主要集中在圆形Packing问题以及矩形排样问题。在国外，其求解算法包括贪心算法、拟人算法、遗传算法、模拟退火算法等，但都有其局限性。本课题研究的是给定长、不限高度的无限区域内互不重叠的优良布局，通过对多种算法进行比较，比较多种算法之间的算法效率，对解决Packing问题得到整体最优解有较大帮助。                                                                 |

| （3）运用的理论与方法                                                                                                                                                                                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                                                                                                                                     |
| 1.贪心算法：建立数学模型来描述问题，把求解的问题分成若干个子问题，对每一子问题求解，得到子问题的局部最优解，4.把子问题的解局部最优解合成原来解问题的一个解。                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                                                                                     |
| 2.拟人算法：占角――每次向矩形容器中放置矩形块时，总是占据某个角，而且动作的穴度还要尽量大，这样放置就可使矩形块之间挨得很紧，减小了对空间的浪费，从而提高了面积的利用率。聚类――面积相等或相近的矩形块最好能凑在一起，经组合后形成一块更大的矩形块，从而减小了问题的规模。                                                                                                                            |
|                                                                                                                                                                                                                                                                                                                                                                                                     |
| 3.遗传算法：遗传算法（Genetic Algorithm）是一类借鉴生物界的进化规律（适者生存，优胜劣汰遗传机制）演化而来的随机化搜索方法。其主要特点是直接对结构对象进行操作，不存在求导和函数连续性的限定；具有内在的隐并行性和更好的全局寻优能力；采用概率化的寻优方法，能自动获取和指导优化的搜索空间，自适应地调整搜索方向，不需要确定的规则。                                                                 |
|                                                                                                                                                                                                                                                                                                                                                                                                     |
| 4.模拟退火算法：模拟退火算法(simulated annealing,SA)作为局部搜索算法的扩展，在每一次修改模型的过程中，随机产生一个新的状态模型，然后以一定个概率选择邻域中能量值大的状态。这种接受新模型的方式使其成为一种全局最优算法。                                                                                                                                                                            |
|                                                                                                                                                                                                                                                                                                                                                                                                     |
| （4）预期目标与结果                                                                                                                                                                                                                                                                                                                                                                                 |
|                                                                                                                                                                                                                                                                                                                                                                                                     |
| 实现一个拥有简明命令的界面软件，算法所需要的数据可通过用户进行输入或从电脑文件中读取来获得。用户可通过用户鼠标操作进行切换算法，实现对不同算法的计算。在读取数据后，实现算法并在图形界面中以图形方式显示算法结果，同时显示运行该算法的时间效率以及该算法最终的占用率。用户可以通过比较这些算法的算法效率来确定得到Packing算法最优解的算法。                                                         |
