## 调研收敛（2024-2025 文献+开源实践）

1. **grounding 是主流解法**：LLM 生成测试的弱预言问题，2024-2025 的缓解主策略=把生成锚定在
   API 文档/规范/领域知识上——RAG、微调、意图提取（"Domain Knowledge is All You Need"金融域
   实证 380845052；"Test Intention Guided"意图驱动 oracle；程序无关生成工具用"库/设计文档/
   配置文件"而非仅源码做 grounding）。TU Delft 实证：**software context 直接影响 oracle 质量**。
2. **测试运行器反馈的迭代生成**（Self-Refining）：与本课题 R-Loop 回灌同思想，文献证实显著
   改进——本项目的方向被文献背书。
3. **"语言陷阱清单"无直接文献**（学术词=test smells/anti-patterns/flaky）——**curated 清单
   本身是空白点**，做出来即有新颖性（组合创新：清单×错误推测法×消融验证）。
4. 开源实践映射：Keploy=流量录制作真实行为锚点（与本方案 A 源同思想）；Diffblue Cover=内置
   领域启发式（B 源同思想）；SymPrompt=repo 内符号上下文（C 源同思想）。

## 价值评估（2026-10-31 09:00，诚实版——回应"确定有用吗"）

**不确定全部有用，分开说**：

- **C 源（docstring）最有把握**：g2 失败实锤是"行为语义猜错"，docstring 是行为规范的第一来源，
  风险低、确定性高。先做这个。
- **A 源（repo 校准）有用但有一个必须正视的张力**：把预期对齐"自带测试已验证的行为"，
  本质是**对齐实现现状**——与本课题"防断言迁就"（2412.14137：生成器会验证 bug）的主线
  **存在冲突**：若实现有 bug 且自带测试恰好没覆盖，锚点会把预期锚在 buggy 行为上，加剧迁就。
  正确定位：A 源只锚定 **API 用法层**（怎么正确调用库、参数形态、异常类型），**不锚定预期
  输出值**。实施时必须这样切分，否则会伤害核心设计。
- **B 源（陷阱库）是赌注**：文献空白=无先例证明有效；且本课题自己的消融已有前车之鉴——
  **发现二证明"流行的五法骨架对检出率无贡献"**。陷阱库很可能同样无效（提示词变长但检出不变）。
  但负结果与发现二互证（"静态知识注入对检出无效，瓶颈在预言侧"强化），**作为实验一定有价值**。

**确定性排序**：论文素材价值（三源消融无论正负都可写）> C 源 > A 源（限用法层）> B 源（赌注）。
**实施建议**：C 先行 → A 限用法层 → B 最后（小额验证，负结果如实写）。

## 具体实现思路（2026-10-31 09:10，可直接开工）

### C 源·docstring grounding（先做，~半天）

1. **提取**：gen_tests 新纯函数 `_extract_api_docs(ws, max_chars=2000)`——AST 遍历
   （与 _module_top_level 同源），取 module 级 + 顶层函数/类的 `ast.get_docstring()`，
   渲染为 `### tenacity.stop_after_attempt\n<docstring 原文>`，超预算截断（优先含
   "Args/Returns/Raises" 段的）。
2. **注入**：build_user_prompt 新参数 `api_docs`，插在"被测文件"段之后；加纪律行：
   "预期值与 docstring 冲突时，以 docstring 为准，expected_basis 标『docstring文档』"——
   **expected_basis 枚举里现成有「docstring文档」**，零改表。
3. **消融**：X-C 格 `{DOCSTRING_GROUNDING_ENABLED: True}`（新开关默认关）。
4. **判据**：g2 类"行为语义猜错"失败减少率（用 tenacity 语料重放对比）；expected_basis=docstring
   的标注占比（grounding 生效证据）。

### A 源·repo 校准（~半天，防迁就是红线）

1. **提取**：`_extract_usage_examples(ws, limit=5)`——只扫自带 tests/ 里 import 被测包的函数，
   摘取**调用形态**（函数名+实参形态+with pytest.raises 的异常类型），**剥除断言行**——
   只示范"怎么调用"，预期值由 docstring/需求决定（防迁就切分线）。
2. **注入**：提示词段"仓库自带测试的调用用法（仅示范调用方式，不是预期值来源）"。
3. **消融**：X-A 格。
4. **判据**：①类失败中"调用形态错误"子类是否消失；**监督指标：全过率不得因 A 源上升**
   （上升=迁就发生，回滚）。

### B 源·陷阱库（~半天）

1. **清单**：`prompt_library.PITFALL_KB = {"python": [...8条], "web": [...6条], "cli": [...4条]}`，
   每条 {pattern, why, test_hint}（如 {"pattern": "浮点数相等比较", "why": "IEEE754 精度",
   "test_hint": "用 abs(a-b)<eps 或 pytest.approx"}）。
2. **选择**：analyze 出的语言 + 需求关键词（FastAPI/flask→web）选前 3-5 条，注入 T5 错误推测
   skeleton 的扩展段（METHODS 注入，与五法骨架同通道）。
3. **消融**：X9 格 `{PITFALL_KB_ENABLED: True}`。
4. **判据**：检出率 + 陷阱相关用例占比（"trap 关键词"在生成用例中的出现率）——负结果如实写
   （发现二先例）。
