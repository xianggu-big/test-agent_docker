## 六、踩坑记录

1. **modules 表 FK/UNIQUE 双撞**：合并项目时只搬 test_tasks 会撞 `modules` 的 UNIQUE(project_id,path) 和 FK——必须先按 path 合并模块并改写 `test_scripts.module_id`。
2. **`max(pool)` 字典序**：Python 版本键按字符串比会让 "3.9" 大于 "3.13"——必须按数字元组排序。
3. **白名单与生成器不一致**：确定性配方生成 `pip install pytest pytest-cov`，白名单只允许单包 → 补"工具链组合"模式（仍限定固定包集合）。
4. **`.tab` → `.fchip` 改名后 JS 绑定失效**：HTML 换类名时选择器必须同步（Playwright 断言"筛选走服务端"抓到）。
5. **队列 prep 分支漏掉 hybrid 代审钩子**：旧 `_prep_worker` 里有，搬到队列后必须补（否则 hybrid 模式静默退化）。
