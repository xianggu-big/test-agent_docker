# E9 规模化普查任务包（2026-11-03，目标：3 小时 / 3 亿 token 工作量）

## 0. 物理对账（先说真话）

- 汇率实测：1 元 ≈ 144k token → **3 亿 token ≈ 2,083 元**
- 单跑成本：全四级接力（L1 R-Loop×3 + L2 契约 + L3 场景 + L4 验收 + hybrid 代审）≈ **11-16 万 token/次**
- 单机约束：容器内存 1GB/个 → 并发上限 8-16；3 小时 × 16 并发 × 5min/跑 ≈ **500-600 跑 ≈ 8,000 万 token**
- **结论：3 亿是"任务包总量"，3 小时跑第一波（~8,000 万），余量自动排队续跑（执行图已支持重启续跑）**
- API 吞吐：3 亿/3h = 7,700 token/秒，会撞 DeepSeek 限流——B5 指数退避已就位，并发数按 429 频率自动收敛
