## 1. 【P0】UI 导航 A+B 双修（用户实锤，已定稿方案）

**用户原话**：任务列表点某个任务跳到报告页，会自动跳到最新的任务不是我点的那个。

**根因（已定位，勿重新排查）**：`test_agent/api/static/app.js`
- `:1073` `viewReport(id)`：先 `location.hash = "#/reports"` → hashchange 触发 `:121` `refreshReports()`
- `:1082` `refreshReports` 末尾 **无条件** `$("rp-task").value = String(tasks[0].id); await loadReport()` ——重置为第一个（最新）任务
- `viewReport` 靠 `setTimeout(…, 150)` 才把用户点的 id 塞回去 → **竞速**：列表渲染快则用户的选择被顶掉

**A=杀竞速**（改 3 处）：
1. 模块级新增 `let REPORT_PENDING_TID = null;`
2. `viewReport`/`viewLogs`：改为 `REPORT_PENDING_TID = id; location.hash = "#/reports";` ——**删掉 setTimeout**；若当前已在 `#/reports`（hash 不变不触发 hashchange）则直接调 `refreshReports()`
3. `refreshReports` 末尾：`const want = REPORT_PENDING_TID && tasks.some(t => t.id === REPORT_PENDING_TID) ? REPORT_PENDING_TID : (tasks[0] && tasks[0].id); REPORT_PENDING_TID = null; if (want) { $("rp-task").value = String(want); await loadReport(); }`

**B=列表行改走详情页**：
- `:1019` `.pg-task` 行 `onclick` 从 `viewReport(Number(tr.dataset.tid))` 改为 `location.hash = "#/task/" + tr.dataset.tid`
- 行内已有的 `<a href="#/task/${t.id}">`（失败原因/实时进度）不变；`javascript:viewReport(...)` 的"报告"按钮不变——报告页只由它进
- `e.target.closest("button")` 的放行判断扩成 `closest("a,button")`（行内链接/按钮点击不触发行跳转）
