# 论文格式规范（从过关范本 thesis_format_ref.docx 提取，2026-10-30）

> 用途：论文终稿排版依据。范本 docx 本身不入库（含他人个人信息，已 gitignore），本文件是格式的持久化提炼。

## 页面与版式
- A4（21×29.7cm）；边距：上下 2.00cm、左右 2.60cm
- 正文：12pt（小四），行距固定值 20pt；样式表直接复用范本 docx（Heading 1/2/3、Normal 已定义好，终稿以其 styles.xml 为基底）

## 结构顺序（无编号区 + 编号章 + 尾部区）
1. 封面（个人信息，学院提供）
2. 【摘要】…【关键词】词1 词2 …（方括号风格，中英文）
3. 目录
4. 引言（H1 无编号，正文前短引言）
5. 第1章 绪论（1.1 背景与意义 / 1.2 研究现状 / 1.3 主要研究内容 / 1.4 论文结构）
6. 第2章 核心技术与开发环境（技术介绍 + 开发环境 + 本章小结）
7. 第3章 系统需求分析（可行性 / 业务流转 / 功能需求 / 非功能需求 + 本章小结）
8. 第4章 系统设计（总体架构 / 模块详细设计 / 数据库设计 + 本章小结）
9. 第5章 系统实现（核心实现 + 各端界面展示 + 本章小结）
10. 第6章 系统测试（测试方法 / 用例与结果 / 测试总结）
11. 结论（H1 无编号）
12. 致谢语 / 参考文献

## 惯例
- 每个编号章末尾设「本章小结」（H2）
- 图表编号按章：图 4-1、表 6-2
- 参考文献格式终稿阶段从范本抽取样例核对（GB/T 7714 预期）
