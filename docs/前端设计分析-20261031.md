## 4. 前端计划（组件拆分/路由/断点）

**路由**：保留现有 5 页（新建/工作台/任务列表/报告/设置）不变；**新增 `#/task/{tid}` 任务详情页**（设计图主体），报告页保留（深度分析用），任务列表/报告的"查看"入口指向详情页。顶部导航（设计图 4 项）映射：测试任务→#/tasks、报告中心→#/reports、镜像管理→#/settings（锚点）、执行环境→#/settings（锚点）——顶导航与 sidebar 并存（桌面）。

**组件分桶**：新建=task-hero/req-card/sec-title/level-card2/pipeline/status-pill/defect-panel/empty-state；改造=topbar（胶囊组）、trace-panel（升级）、level-grid→详情页复用 level-card2；复用=metric-row/tbl/badge/tabs。

**断点**：≥1200 全量（4 列卡）；768-1199（2 列卡+sidebar 收窄）；<768（单列+sidebar 折叠为顶部横向滚动导航+顶栏胶囊缩为点）。

**排序纪律**：四级卡/溯源链/流水线/真数据 = 不可砍；视觉打磨次之；动效/SSE 最后（砍单）。
