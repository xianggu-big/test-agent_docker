## D1【P0·语义】源码预算 8000 字符 + 超限静默跳过 → 真实项目只喂 setup.py

- 证据：`MAX_SOURCE_CHARS = 8000`（test_agent/skills/prompt_library.py:129）；
  `_collect_sources`（gen_tests.py:52）按路径排序整文件收录，超预算文件**直接 continue，无任何告警**。
- 实测（precheck_candidates.py）：
  - python-titlecase：LLM 只看到 `setup.py`（625 字符）；`titlecase/__init__.py`（10,608 字符）静默跳过
  - schema：LLM 只看到 `setup.py`（1,516 字符）；`schema/__init__.py`（37,766 字符）静默跳过
  - more-itertools：`more.py`（176,022 字符）必跳过
- 影响：**所有真实 GitHub 库都超限**——生成器看不到被测代码，生成的用例是废的；
  此前所有 demo 语料（calc.py/cart.py/coupon-api）都是微型单文件项目，从未暴露。
- 修复方向：①按函数定向提取（AST 切片 `file::function`，按 plan 条件/RTM/热点选函数）+ 预算上调；
  ②打包文件（setup.py/setup.cfg/pyproject.toml）永不挤占包源码预算；③跳过时 session 日志 + 指标如实告警。
- 状态：**已修（2026-10-31，fd4cb8e）**——预算 24000/整收阈值 12000/大文件顶层符号切片+模块级常量段/
  噪声文件排除（并入 D5）/语法坏文件台账/source_skipped 进返回 JSON+日志。
  预检复验：titlecase 625→**10608 字符整文件**，schema 1516→**12839 字符 20 切片**。
  （"按 plan 条件/热点定向优先级"留 v2——当前按序收录已消除盲写根因）

## D2【P1·健壮】git clone 无直连回退，代理失效环境真实 GitHub URL 全炸

- 证据：nodes.py:134 直接 `git clone`，git 走系统代理；本机代理已死（127.0.0.1 拒连），
  真实 URL 克隆必失败且报 env 类错误；codeload tarball（`--noproxy`）实测可达。
- 影响：真实 GitHub 任务在本环境走不通（本会话 H1 用本地目录快照绕过，clone 节点 `os.path.isdir` 分支）。
- 修复方向：git 失败后回退 codeload tarball（确定性、无代理依赖）；失败信息提示"可用本地目录路径"。
- 状态：**已修（2026-10-31）**——codeload tarball 回退（显式绕代理，main/master 双分支，
  手写解包剥顶层+穿越防护），回退与否都留痕；调研结论=GitPython/dulwich/pygit2 均
  git 协议实现同样依赖代理、无现成回退轮子、不引重依赖。真机验证：有效仓 12 文件落盘、
  失效仓（heapdict）两分支 404 如实 None。

## D3【P2·闸失效】静态闸对包项目（`__init__.py`）盲区

- 证据：`_module_top_level`（gen_tests.py:127）用文件 stem 做键；包的入口 stem 是 `__init__`，
  `from titlecase import titlecase` 的 mod=`titlecase` 不在表里 → 闸**不检查直接放行**。
- 影响：宽方向失效（不误杀但闸名存实亡），包项目生成用例的 import 校验形同虚设。
- 修复方向：把包目录名映射到其 `__init__.py` 顶层符号。
- 状态：**已修（2026-10-31，随 fd4cb8e）**——`__init__` 映射包目录名，单测锁（存在过/缺失拒）。

## D5【P2·语义】tests.py 等测试文件被当作被测源码收录

- 证据：`_collect_sources` 只排除 `test_*` / `*_test.py` 命名；`tests.py`（python-titlecase 实测 14,187 字符）
  被当作被测源码候选，若预算够会喂给 LLM 当"被测代码"。
- 影响：生成器会把测试辅助代码当业务代码测，产出自指废用例。
- 修复方向：排除模式补 `tests.py`/`test.py`/`conftest.py`。
- 状态：**已修（2026-10-31，随 fd4cb8e）**——SOURCE_NOISE_FILES 集合，大小写不敏感。
