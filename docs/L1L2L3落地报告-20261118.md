## 2. L2 覆盖率闭环兜底（急救层，旗标默认开）

**实现**：
- `project_index.coverage_check(state, per_file, coverage_line=None)`：确定性判读。**关键前提**=`--cov-report=term-missing:skip-covered` 省略全覆盖文件、0% 文件必在缺口表——据此：范围内行存在且任一 cover>0=ok；范围内全 0=zero_coverage；范围内缺席+TOTAL>0=ok（skip-covered 语义）；缺席+TOTAL=0=zero_coverage；缺席+TOTAL 缺失=**no_data（测不了就不猜，急救不触发=诚实出口，防假阳性急救烧 LLM 轮）**。
- `config.INDEX_L2_RESCUE_ENABLED = _flag("MTA_INDEX_L2_RESCUE", True)`：校验零成本，重跑成本被 repair_gen 轮次预算天然约束；关=整段跳过。
- `nodes.evaluate` 钩子（verdict 判定后、INSERT evaluation_rounds 前）：**只在 repair_gen 分支触发——指纹熔断/轮次预算给出的 stop 绝不覆盖（急救不得击穿熔断）**。首次零覆盖→闭包 hops 1→2 扩圈（无新增直接回退全库）；已扩圈过→scope 清空回退全库（`index_l2_rescued` 防死循环）。evaluate 返回体补三路由键跨节点（366 教训）。
- **对设计文档的两处边界细化**（报告如实）：①`_l2_rescued` 升格为 state 声明键 `index_l2_rescued`（不声明=LangGraph 过滤=死循环风险）；②coverage_check 增加 no_data/skip-covered 判读（设计原判"文件缺失→zero_coverage"会在全覆盖文件被 skip-covered 省略时假阳性急救）。
