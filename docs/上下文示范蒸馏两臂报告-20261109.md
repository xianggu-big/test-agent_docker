# 上下文示范蒸馏两臂对照报告（期 B，2026-11-09）

> 任务：多测试路线编排（期 A）+ 上下文示范蒸馏（期 B）。期 C（LoRA/QLoRA）只写设计不进代码。
> 期 A 主体：`skills/routes.py`（9 条声明式路线+确定性路由器）+ route_plan 第 33 表 +
> `skills/ui_idempotency.py`（UI 交互幂等路线，oracle=状态不变量）+ analyze/static_draft 接线（MTA_ROUTER 默认关）。

## 一、实验设置

- **ground truth = 期 A 确定性路由器**（`route_plan`，零 LLM）：LLM 不得越过前置条件，
  所以准确率定义 = LLM top-1 是否等于确定性路由器 top-1（这是该指标天然成立的口径，
  因为路由器本身就是"需求+特征→路线"的正确性基准）。
- **样本**：真库 23 条真实需求×项目特征（语言覆盖 unknown/python/go/js/html/sql；
  路线分布 static_scan 14 / l1_unit_pytest 5 / ui_interaction_idempotency 1 /
  ui_static_dom 1 / grpc_contract 1 / db_assert 1）。
- **两臂**：同一系统提示（路线清单摘要+同一份特征串），唯一变量 = 有无 2 条决策骨架
  范例（观察特征→选路线→理由 三段式，共约 223 token，非长 CoT）。
- **模型**：qwen3-4b-inst-test（Ollama 本地，ctx 8192）；temperature=0；每臂
  23 样本 × 3 次采样 = 69 runs。
- **驱动**：`scripts/route_ab_test.py`（样本：`.autonomous-loop/route_ab_samples.json`；
  原始结果：`data/reports/route_ab/route_ab_n3.json`）。

| top-1 路线准确率 | **43.5%**（30/69） | 34.8%（24/69） | **+8.7pp** |

## 三、结论（诚实口径）

1. **能提升多少**：top-1 准确率 **+8.7pp**（34.8%→43.5%）。提升主要来自**分布纠偏**：
   无范例臂把 14 个 static_scan 样本中的大多数误选成 db_assert（15 次误选 vs 真值 1 次
   ——sql 文件特征被过读），有范例臂这种错选基本消失（5 次，static_scan 回到 9 次≈真值 14）。
   **范例的作用不是教模型新知识，是纠"看到 SQL 文件就该测 DB"这类特征过读**——
   与训练偏置类的失败模式（测试设计偏置，防御矩阵 P2 正例锚定同型）一致。
2. **退化在哪**：无。两臂 JSON 可解析率均 100%（路线选择是短结构化输出，qwen3-4b
   无解析压力）；completion tokens +7（范例后理由写得更贴格式）。
3. **上下文预算压力**：范例段 223 tokens，占 qwen3-4b 8192 ctx 的 **2.7%**——
   **可忽略**。真正的 ctx 压力来自 gen_tests 类长提示词（705 实锤 12768 tokens 装不下），
   路由选择的 prompt（604 tokens）远离该边界。
4. **绝对值仍低（43.5%）的诚实解读**：静态_scan 主导的样本分布（14/23）下，
   "unknown 语言→兜底"这类正确答案需要模型克制不选"看起来更有用"的路线——
   这正是期 A 把路由做成确定性代码的理由：**LLM 路由不承担正确性责任，只在候选集内
   辅助排序/解释**。43.5% 的 LLM 独立路由能力 = 论文里"为什么路由器必须是确定性代码"
   的定量证据（若作为设计替代方案，准确率不可接受；作为辅助解释器，可用）。

## 四、期 C 设计（只写设计，不进代码）

**LoRA/QLoRA 路线选择微调（设计稿）**：
- 动机：期 B 实锤 LLM 独立路由 top-1=43.5%，主因是特征-路线映射的系统性偏差
  （db_assert 过读型）。SFT 可直接教映射。
- 数据：确定性路由器可无限产（特征，top-1）对——**无需人工标注**（这是路由任务
  独有的优势：oracle 免费）。建议 2k 条（特征空间覆盖：语言×manifest×特征组合）。
- 训练：QLoRA r=16 α=32，目标模块 q/k/v/o + gate/up/down；qwen3-4b 4bit 量化基座；
  单卡 24G 可跑；损失仅对 completion（{"primary_route":…}）。
- 验收口径与期 B 同一测试集（hold-out 23 条真实样本+扩充），对照：确定性路由器
  /qwen3-4b base/QLoRA 后三者。
- 风险预判：①过拟合到特征表面模式（static_scan 占比高需平衡采样）②微调后 JSON
  格式漂移（需重测可解析率）③**确定性路由器仍是正确性底线——微调模型只做排序与
  解释，不得越过前置条件**（架构约束不因训练改变）。
- 结论建议：期 B 的 +8.7pp 与纠偏效应说明**提示词工程性价比足够**（成本 223 token）；
  期 C 的边际收益预期主要在 l1/db 之外的细分路线，优先级=低，建议论文只引用本报告
  的两臂数据作为"训练 vs 上下文工程"的对照讨论。
