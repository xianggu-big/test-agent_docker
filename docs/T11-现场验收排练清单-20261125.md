## 三、排练动线（15 分钟版）

1. **开跑前自检 6 项**（黄金脚本 §0）——全绿才开演。
2. 演示步 1-3（2 分钟）：caller 建任务→dev 确认→下发；顺口指出"每一步都有权限闸"。
3. 演示步 4（3 分钟）：`#/run/{rid}` 决策时间线——读证据🔧/策略闸拒绝⛔/finish🏁；讲"图拓扑固定、模型只决定节点内调用"。
4. 演示步 5-7（4 分钟）：流水线+日志流 [evaluate]→报告页 clamp 检出；讲"证人冻结，宁可误报不可造假"。
5. 演示步 8-9（3 分钟）：四指标头部→导出回放 JSON；讲"可重算可回放，重跑不覆盖"。
6. 负例三条（2 分钟）：caller 下发 403 / 未确认 409 / Skill 停用审计行；讲"治理边界全落审计"。
7. 备查（被追问才开）：指标表 v0+指标契约+四表快照；skill_demo 六场景。

## 四、高频追问预案

| 追问 | 答法 |
|---|---|
| "重跑会覆盖吗？" | 不会——运行账本 attempt_no 递增+终态快照 summary_json（现场：同任务两次运行并排对比面板） |
| "怎么防 Agent 改产品代码？" | 策略闸+图路由双层：capability 菜单无写产品权限；diagnose 永不写 verdict（`agent_nodes.py` 铁律注释） |
| "断言错了算谁的？" | 归因三闸+四分类（product_defect/case_defect/env/expectation_dispute），A1 堆栈首帧归属（`repair.py` classify_failure） |

| "测量批跑出什么？" | 见完工报告③ §1（批后填）——成功判据是数据完整性不是性能阈值 |
