## 2. 重新设计：三波充值触发制

### Wave 1 小样校准波（~50 万 token，半天开发+1h 跑）——**先小样再放量（批3 铁律）**
1. **R1 烟测 1 格**：deepseek-reasoner preset + 思考链单独记账（llm_calls.model 区分）
   ——先验证 zcode 赠款通道**是否支持 reasoner**（可能 404/无权限，失败=Arm 2 降级
   为"chat 自审 vs chat 互审"，如实改口径）；
2. **Arm 1 对照设计验证 5 格**：失败语料聚类→陷阱库 v2 注入→带知识重跑 vs E9-A1
   同任务无知识基线，5 格先看方向（若 5 格全负，Arm 1 主力波缩半）；
3. **Arm 3 生成器 1 序列 3 步**：演进算子确定性实现（参数变更/边界移动/缺陷再植入），
   3 步全接力验证退化曲线可测。
Wave 1 出**继续/缩量/砍 Arm** 决策点，再进 Wave 2。

### Wave 2 主力波（~1200 万 token）
- **Arm 1 失败知识反哺 ×3 轮**（100 任务/轮，每任务带 E9 失败签名+陷阱注入重跑；
  对照=E9-A1 基线零成本）——核心指标：每轮检出/覆盖率信息增量是否收敛；
- **Arm 2 R1 交叉矩阵**（chat 生成×R1 审查 + R1 生成×chat 审查，3 语料 × n=5）
  ——R1 思考链重 token 按实测加权。

### Wave 3 深挖波（~800 万 token）
- **Arm 3 演进长跑**：10 项目 × 15 步 × 全接力（实测 ~21k/格 → 315 万）；
- **Arm 4 oracle 对抗**：A3 投票 oracle 投变异场（本地重放）→ 杀死率 vs 单断言基线
  → 低分 oracle R1 重写再投（重写 ~50 万）；
- **Arm 5 分歧精炼**：A3 K 曲线内分歧 top 条件 ~500 条定向再生成三轮投票收敛。

## 3. 护栏（继承 E9 全套 + 三条新纪律）

1. 继承：llm_calls 实时停车线（每波独立）/ 失败率>20% 降并发 / 每格 JSON 留档 /
   **高峰时段门**（09-12/14-18 禁新格，用户硬规则）；
2. **新：实验格不走 local 备胎**——E9 教训（降级格混口径只能靠标记分账）：
   E10 格撞 402 直接标 budget_exhausted 留档停波，**不降级**（实验数据纯净性优先
   于格完成率）；刚修好的格级进程内覆盖能力保留给生产链路；
3. **新：两本账对账进聚合**——驱动器 JSON（实验口径）vs test_tasks（平台口径）
   每波聚合时对账差异行数（E9 实锤 487 vs 518），差异原因分类入报告；
4. **新：负结果预注册**——Wave 1 前写下每 Arm 的"什么结果算负结果"（Arm 1 无
   提升方向=发现二规模化复现；Arm 2 R1 与 chat 一致性无差=推理模型审查价值存疑），
   跑完按预注册口径如实写，防事后解释。

## 7. Wave 1 校准结果（2026-11-16 13:3x 实跑，预注册口径判定）

**Arm 1 对照 5 格**（corpus-003，基线=E9 原格零成本）：

| 格 | E9 基线 过/败 | E10-trapkb 过/败 | token | 耗时 |
|---|---|---|---|---|
| 523→1249 | 11/6 | **26**/8 | 26,369 | 67s |
| 524→1250 | 27/5 | **33**/9 | 27,102 | 68s |
| 525→1251 | 20/7 | 10/4 | 24,025 | 65s |
| 526→1252 | 20/7 | 11/6 | 32,644 | 81s |
| 527→1253 | 29/6 | **30**/8 | 26,883 | 76s |

- 合计通过：基线 107 → trapkb 110（**+2.8%**）——**方向为正、幅度小、格间方差大**
  （单格 -50%~+136%）；n=5 不足以判定 → **预注册判定：继续 Wave 2（n=100/轮），
  用统计显著性说话**；
- 注入通道全链生效（trapkb=ON，提示词含【历史 285 例】簇警示）；
- 单格均耗 ~27k token（实测）——Wave 2 预算 300 格 ≈ 810 万 token ≈ ¥6-26。

**Arm 2 R1 烟测**：通道可用但映射为 flash+思考链（口径改"思考链开关对照"）。
**Arm 3 生成器**：3 步序列 plan/apply 验证通过。
**校准决策：Wave 2 按设计点火（低价窗）**。
