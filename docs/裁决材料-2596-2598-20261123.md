## 1. #2596 python-six 逐条证据

### BUG-02 print_（4 条参数化）

断言原文：`assert six.print_(value) == expected`（expected 全是字符串 `'None'`）。
实际：`AssertionError: assert None == 'None'  +  where None = six.print_('""')`。
six 源码：`print_ = getattr(builtins, "print")`（py3 直通内置 print）→ **无返回值**。用例把"打印 None"误当成"返回 'None'"。**六本身无缺陷。**

### BUG-01 add/remove_move 判定表

断言原文三连 + 宿主复现结果（`sys.path` 指向本仓库 six.py，与容器同源码）：

```text
断言1  hasattr(_MovedItems,'_test_move_xyz')（add_move 后）  → False ✗（用例期望 True）
断言2  remove_move 后 not hasattr                            → True ✓
断言3  二次 remove_move 抛 AttributeError                     → 确实抛 ✓（用例这条写对）
```

根因（six.py:96-98）：`_LazyDescr.__get__` 首行 `setattr(obj, self.name, result)`——经**类**访问时 `obj=None` → `setattr(None,…)` 抛 `AttributeError` → `hasattr` 吞掉返回 False。**这是 six 惰性描述符的既有语义，不是缺陷**；`add_move` 的 `setattr(_MovedItems, …)`（six.py:515）也是为**实例**访问（`six.moves.xxx`）设计的。经实例复现：`hasattr(six.moves,'_test_move_xyz')` → True；`remove_move` 后 → False；二次 `remove_move` 抛 AttributeError（six.py:520-527 确实会 raise）。
**结论：用例访问形态写错（类 vs 实例）；六本身无缺陷。**

## 2. #2598 js-dayjs 逐条证据（容器 mta-test:node20-jest 真机复现）

复现环境：`docker create dayjs-repro`（mta-test:node20-jest）+ 仓库拷入 + `npm install`（moment 2.29.2 / moment-timezone 0.5.31，与 package.json 精确钉版一致，无依赖漂移）。

### BUG-01 locale（generated）

复现双臂（`locale.repro.test.js`，SUT=仓库 `src/`，与平台同解析路径）：

```text
✓ 臂1 未注册 locale（生成用例形态）→ dayjs().locale('zh-cn').locale() === 'en'
✓ 臂2 先 require('src/locale/zh-cn') 注册          → .locale() === 'zh-cn'
```

生成脚本 imports 段只有 `require(path.join(__dirname,'src/index.js'))`，**全文件无 locale 注册**。dayjs 文档明示：locale 需先 import 注册再用；未注册即回退全局默认 'en'（设计行为）。**用例夹具缺失，非缺陷；加一行注册即过。**

### DST edge cases（repo 自带，`test/plugin/timezone.test.js:483`）

先证伪"容器时区不对"假设：五个 TZ（UTC / America/New_York / Europe/Paris / Europe/London / Pacific/Auckland——repo test script 规定的全集）下**全部同样失败**（Expected `-04:00`（moment）vs Received `-05:00`（dayjs）），与 host TZ 无关。

再证真因——日期依赖（`dst-date.deps.test.js`，MockDate 冻结"当前时刻"）：

```text
✓ 夏天（2024-07-01 当"现在"）→ dayjs.tz('2012-11-04 01:00', NY) 解析为 -04:00（与 moment 一致，测试绿）
✓ 冬天（2024-01-15 当"现在"）→ 同一输入解析为 -05:00（平台失败形态，测试红）
```

机制（`src/plugin/timezone/index.js` `d.tz` → `fixOffset`，luxon 移植）：解析歧义本地时间的**初始猜测 `o0 = tzOffset(现在, tz)`**；冬天"现在"是 EST(-05:00) → 猜中短路返回 EST；夏天是 EDT(-04:00) → 返回 EDT。moment 按规范恒取回拨前第一次出现（EDT）。任务 #2598 跑于 2026-11-23（EST 期）→ 红。**上游 dayjs↔moment parity 测试自身日期敏感（约每年 11 月初~3 月中跑会红），非平台缺陷、非生成用例问题。** 上游 dev 分支同段逻辑未改（2026-11 核对）。
