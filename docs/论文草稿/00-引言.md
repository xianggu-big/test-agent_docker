# 引言（无编号 · 正文前短引言）

软件质量保障离不开系统化的测试，但传统测试流程高度依赖人力：测试条件靠人工从需求中拆解，用例靠人工按设计方法逐条构造，执行环境靠人工搭建维护，评估报告靠人工核对汇总。大语言模型的成熟使"从需求直接生成测试"成为可能，但实证研究表明，现有生成器存在断言迁就实现行为、执行结论不可复现、方法组合缺乏量化对比三类结构性问题——直接套用 LLM 并不能得到可信的自动化测试。

针对这些问题，本课题构建了一个基于大模型 Agent 与容器技术的四级双轨自动化测试系统：以固定图编排使测试流程确定、可复现、可审计，以容器沙箱保证执行结论的可信，以证据链机制保证发现的缺陷不被系统自身掩盖，并以盲测语料与控制变量实验量化各方法组件的实际贡献。本论文报告该系统的设计、实现与实验结论。
