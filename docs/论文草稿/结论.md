# 结论

本文围绕"大模型生成的测试是否可信、可复现、可归因"这一问题，完成了基于大模型 Agent 的黑盒白盒自动化测试方法的研究与系统实现，主要工作与结论如下。

**在方法与系统层面**，本文以测试四阶段为顶层结构、以固定状态图为编排骨架，实现了单元级九节点主图与集成级、系统级子图的串行接力，形成四级递进的应用对象；黑盒方法骨架（等价类、边界值、判定表、状态迁移、蜕变、错误推测、属性测试）与白盒覆盖反馈（覆盖缺口回灌、调用链分析、复杂度热点、变异标定）双轨贯穿各级，系统级与验收级以"自动判定、失败人工介入"和"确认转化"的半自动方式落地。针对大模型生成器"断言迁就实现"的实证缺陷，构建了生成三道闸、归因三分类、缺陷证人冻结、报告审查双闸与预期值来源标注组成的机制链——系统不承诺"直到成功"，而是在达标、熔断或预算耗尽时带证据链如实上报；已逐批复核的实验批次中证人语义零违反，其余任务轨迹由台账留档可复核。

**在实验评价层面**，本文建立并执行了一套可控真值方法：三方盲测语料协议（含占位条目剔除分母的修正）、"每次只改一个开关"的消融矩阵与变异测试标定。实验得出六点主要结论：其一，在 Windows 宿主环境下，容器化执行不引入性能惩罚，常驻容器热运行较宿主直跑快约 3.8 倍；其二，剪除式修复确定性最强，混合式修复以小成本换取鲁棒；其三，失败归因器在变异标定校准后全部正确，归因准确率从经验陈述变为可量化指标；其四，报告审查双闸将注入的四类失真报告全部拦截、合规对照通过；其五，测试分析层（需求到测试条件的显式拆解）对缺陷检出率有跨复现稳定的正贡献，而方法骨架本身不驱动检出率——这是一项如实报告的反直觉发现；其六，缺陷检出的瓶颈位于测试预言侧（断言驯化），且该现象在同一语料上跨全部消融配置复现，为"断言独立性约束"的后续改进提供了直接动机。

**研究局限**主要有：实验样本量有限（部分实验为单次运行），被测对象为微型模块与小型服务，出题与答题环节为同源模型，结论外推到大型仓库需谨慎；系统当前面向 Python 深度支持，未治理不稳定测试。

**未来工作**将沿三条线推进：一是断言独立性实验——在语料中强制预期值不得来源于实际输出，对症处置预言侧瓶颈；二是语料与模型异构化——扩大语料规模、引入异构出题模型与 Web 形态被测对象，并完成级别扩展实验（集成层双轨消融、跨级溯源命中率、四级评价矩阵）的复跑；三是工程深化——容器网络互通的双容器模型、持续集成接入与不稳定测试治理，使系统能够在真实流水线中长期运行。
