# 摘要

软件测试是保障软件质量的核心环节，但测试用例的设计与执行高度依赖人力；大语言模型虽能从自然语言需求直接生成测试用例，却存在断言迁就实现行为、执行结论不可复现、方法组合缺乏量化对比等结构性问题。针对上述问题，本文提出并实现了一种基于大模型 Agent 的黑盒白盒自动化测试方法：以测试四阶段（分析—设计—执行—评估）为顶层结构，以固定状态图编排测试流程、大模型规划作为节点产物，以容器沙箱承载隔离可复现的执行环境，以单元、集成两级深度自动化与系统、验收两级半自动辅助构成四级递进的应用对象，黑盒方法骨架与白盒覆盖反馈双轨贯穿各级。在机制层面，构建了生成三道闸、失败归因三分类、缺陷证人冻结、报告二次审查双闸与全链路审计台账的质量保障链，并以预期值来源标注约束断言的生成。在评价层面，建立了出题人—答题人—阅卷人三方隔离的盲测语料协议、控制变量消融矩阵与变异测试标定方法。实验结果表明：容器化执行不引入性能惩罚（Windows 宿主环境下热运行较宿主直跑快约 3.8 倍）；归因器经 14 例变异标定校准后全部正确；报告审查双闸可拦截全部注入的失真报告；消融实验显示测试分析层（需求到测试条件的拆解）对缺陷检出率有跨复现稳定的正贡献，方法骨架不驱动检出率，而瓶颈位于测试预言侧且在同一语料上跨配置复现；质量组件不损伤检出率并出现正向信号。本方法为可信、可审计、可复现的大模型自动化测试提供了一个完整参考实现。

**关键词**：大语言模型；软件测试；测试自动化；黑盒测试；白盒测试；智能体

# Abstract

Software testing is a core activity of quality assurance, yet the design and execution of test cases remain labor-intensive. Although large language models (LLMs) can generate test cases directly from natural-language requirements, existing generators suffer from structural problems: assertions that accommodate the implementation, non-reproducible execution, and a lack of quantitative comparison among method combinations. This thesis proposes and implements a black-box and white-box automated testing approach based on LLM agents. The approach organizes the testing process by the four-stage model (analysis, design, execution, and evaluation), orchestrates the workflow with a fixed state graph in which LLM planning is a node artifact rather than a flow controller, runs generated tests in containerized sandboxes for isolation and reproducibility, and applies the two-track method family—black-box design skeletons and white-box coverage feedback—across four test levels with progressive depth: deep automation at the unit and integration levels, and semi-automatic assistance at the system and acceptance levels. A quality-assurance chain is constructed, consisting of three generation gates, three-way failure attribution, frozen defect witnesses, dual-gate report review, and full-chain audit ledgers, together with expected-value source annotation that constrains assertion generation. An evaluation methodology is established, comprising a three-party blind-test corpus protocol, a controlled-variable ablation matrix, and mutation-based calibration. Experimental results show that containerized execution introduces no performance penalty (warm runs are about 3.8 times faster than direct host execution on a Windows host); the attribution classifier correctly classifies all 14 injected defects after calibration; the dual-gate report review intercepts all injected distorted reports; ablation experiments reveal that the test-analysis layer (decomposing requirements into explicit test conditions) contributes a stable positive effect on defect detection across reruns, that method skeletons do not drive detection, and that the bottleneck lies on the test-oracle side and reproduces across configurations on the same corpus; quality components do not harm detection and show positive signals. The approach provides a complete reference implementation for trustworthy, auditable, and reproducible LLM-based automated testing.

**Key words**: large language model; software testing; test automation; black-box testing; white-box testing; agent
