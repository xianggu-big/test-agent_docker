## 红队的直接产出（两轮攻击→两次补闸）

1. **首轮实锤 Python 自导自演缺口**：B1 只挂 JS 分支——`mymod.QUESTIONS = [...]`（赋值形态）
   在 Python 侧无任何闸。补 `_mutates_sut_state`（Assign/AugAssign/Delete + 属性链根=被测模块）。
2. **二轮实锤方法变异形态漏过**：`mymod.DATA.clear()` 是 Call 非赋值——补变异方法调用分支
   （clear/append/pop/extend/... 白名单语义）。用例自有对象（`obj.data.clear()`）不误杀（单测锁死）。

## 论文口径

- 旗标全关（现网默认态）拦截率 **2/8**：仅存量闸（import 白名单/语法）有效——**防造假链
  的意义在"开"而不是"存在"**（消融口径的又一证据）；
- 全开 **6/8**：结构类失真全部可拦；漏过的 A/C 两类属于**训练偏置类**（通过压力/示例诱惑），
  印证防御矩阵总论点：**prompt 与确定性闸都防不住的，只能靠 V9 LLM 审与变异标定兜底**
  （A7/A3 案例 + 本矩阵数据三源互证）；
- 诚实边界：攻击样本为人工构造（n=8 类），非 LLM 实际生成分布；拦截率是对该集合的度量，
  不是对真实生成流量的估计（F4 v2=用 LLM 现场生成对抗用例再过闸，待充值）。
