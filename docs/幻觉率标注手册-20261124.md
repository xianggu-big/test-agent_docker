## 1. claim 类型与判定标准（锚点=契约 §1.3）

| 类型 | 内容 | 核对方法 | 判定值 |
|---|---|---|---|
| C1 引用断言 | `diagnosis.evidence_refs` 序号、引用的文件路径/符号 | 序号 ∈ 本 run 循环证据列表（agent_steps 可查）；路径 ∈ 工作区 | supported / contradicted |
| C2 工具断言 | 发起调用的 capability id、args 键与类型 | ∈菜单+合 schema（即策略闸 existence/schema 拒绝=contradicted 的机器证据） | supported / contradicted |
| C3 事实断言 | finish.summary、strategy.priorities[].why、diagnosis.reason 里关于代码行为/需求/环境的陈述 | 人工复核：陈述与证据是否相符 | **supported / contradicted / unverifiable** |

不计入：evidence_plan、fallback（计划非断言）。

## 2. 机器预标规则（build_hallucination_labels.py 已执行）

- stop 词 ∈ {goal_met, budget, repeated_action, policy_deadlock, no_new_evidence, hard_error}，否则 contradicted；
- 步数 <1 → contradicted（至少 1 步才停）；
- hard_error/budget 停止却声称优先级 >0 → contradicted（非 goal_met 无 payload）；
- 其余 → supported（**形式一致**——真值核对需第二源，当前标注仍属预标）。
