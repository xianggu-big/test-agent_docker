4. **D 不优于 B 的检出（n=1 边界）**：reasoner+loop 检出集合与 chat 完全一致、覆盖率相同——思考链模型在本实验形态下未带来检出增量（成本 ×2.5）。n=1 不足以定论，方向性读数=与 Agentless 悖论同向。
5. **agent 账本（12 格 B/D）**：denied=0（未授权成功=0）✓ / 12/12 格有循环轨迹+审计台账 ✓ / strategy 循环多在 4-5 步止于 repeated_action/no_new_evidence（模型倾向观察不 finish——冒烟发现再证实，finish 引导是调优旋钮）。

## 4. 结论与下一步
