# 参与者指引（一页）

欢迎参与"测试生成对比研究"。你将**独立**为一个小型"会议室预约 API"项目手写单元测试。请先读完本页再开始。

## 你的任务

1. 材料是一个文件夹 `project_clean/`：`REQUIREMENT.md`（需求文本）、`app.py`、`booking.py`、`store.py`（源码）、`requirements.txt`。
2. 在 **60 分钟内**，按你的理解写 pytest 单元测试（建议文件名 `test_*.py`）。
3. 目标：尽可能发现代码中的问题。测试应当**断言明确**（写清你期望的正确行为），不要只"跑跑不报错"。
4. 把你的测试文件放在一个目录里提交（只收 `test_*.py` / `*_test.py`）。

## 规则（红线）

- **独立完成**：不与其他参与者讨论，不询问任何人；
- **可查官方文档**（pytest / FastAPI 官方文档允许），**禁止搜索"该项目的答案/分析"**；
- 禁止修改 `app.py` / `booking.py` / `store.py`（只读它们）；
- 计时从你打开需求文本开始，到提交为止。请如实记录开始/结束时间；
- 做不完没关系，交已完成的部分——**发现不了所有问题是完全正常的**，我们比较的是真实水平分布。

## 附：开始前问卷 3 题（答在提交目录的 `profile.txt` 里，仅用于如实记录水平差异）

1. pytest 熟练度：没用过 / 用过几次 / 熟练；
2. Python Web（FastAPI/Flask）经验：无 / 看过 / 写过；
3. 软件测试课程或实践经验：无 / 有。

## 交付清单

- 一个目录，内含：你的 `test_*.py`（可多个）+ `profile.txt`（问卷答案）+ `time.txt`（开始/结束时间）。
