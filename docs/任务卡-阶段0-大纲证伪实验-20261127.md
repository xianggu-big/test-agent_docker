## 4. 判据（预注册，不许现场改）

- **主判据 H1**：余量项目的格级检出率，B 减 A 不低于 20 个百分点（合并计，附 Wilson 95% 置信区间；每臂不足 30 格一律标"方向性"）。
- **扩展条件**：0-i 上 H1 成立才进 0-ii；否则停在 0-i。
- **护栏 H2**：P3 的误报格占比，B 减 A 不超过 20 个百分点；且 B 臂无依据失败占比不超过 A 臂的两倍（A 为 0 时以 B 不超过 10% 计）。无依据失败用 C7 的预期依据审计函数离线计算（零 API）；不打开它的降级旗标，以免改变任务终态。
- **成本 H3**（只报告，不作硬线）：每格 token 与费用、每格用例数，B 对 A 的比值。若 B 臂用例明显更多，结论里必须注明"增益伴随广度增加"。

**判读**：

| 情形 | 结论 |
|---|---|
| H1 过，H2 过 | 进阶段 1（建最小实现） |
| H1 不过 | 不建大纲库，回设计桌 |
| H1 过，H2 不过 | 大纲必须带"预期依据"约束才能用（账目化是必需件）；先做一次带依据字段的复测再进阶段 1 |

## 5. 大纲（逐字冻结；跑格之前不许改，改动即作废本卡）

### 大纲甲：REST / HTTP API 服务

```
一、功能与输入
1. 每个端点的成功路径：合法请求返回约定的成功状态码，响应字段齐全、类型正确。
2. 每个路径参数、查询参数、请求体字段各做等价类：合法值、非法类型、空值、缺失、超出范围。
3. 数值字段的边界：最小、最大、刚好越界、零、负数；写明上下界是否包含端点。
4. 字符串字段：空串、纯空白、最短、最长、刚好超长、特殊字符、非字符串类型。
5. 请求体格式错误：非 JSON、空请求体、多传未定义字段、必填字段缺失。
二、资源与状态
6. 不存在的资源：查询、更新、删除不存在的 id，应返回约定错误（通常是 404），不得返回成功。
7. 无效输入返回 4xx 而非 5xx，服务不因错误输入崩溃。
8. 重复操作：重复创建、重复更新、对已删除或已取消的资源再次操作，行为须符合约定。
9. 状态流转：每个状态下的合法与非法操作（如取消后能否再取消、再修改）。
10. 关联资源：引用不存在的主资源时应失败，且不留下半截数据。
三、业务规则
11. 时间与区间：格式校验；开始早于、等于、晚于结束；区间是否含端点；相邻、部分重叠、完全重叠三种情况。
12. 计算规则：金额、折扣、汇总；阈值边界（刚好达到、差一点达到）；舍入方式。
13. 持久化：创建后可按 id 查到；更新后查询反映新值；列表与详情一致。
14. 列表：空列表、分页边界、排序、过滤条件及其组合。
15. 并发（如适用）：同时创建或更新同一资源，不产生重复或丢失更新。
16. 错误契约：错误响应结构稳定，同类错误在各端点一致。
四、白盒
17. 对每个处理函数覆盖全部分支（成功、校验失败、未找到、异常）；每个比较运算符在边界两侧各取一值；每个条件分支的否定分支要有能触发它的输入。
五、纪律
18. 每条断言写明预期来自哪里（需求、文档或注释、行业惯例、源码推断）；对实现有疑问时按合理约定写预期并在用例名里标明，不要照抄实现。
```

### 大纲乙：库 / 纯函数模块

```
1. 每个导出函数的典型输入与正确结果。
2. 数值边界：零、负数、极小、极大、刚好等于上下限、刚好越过上下限；写明上下限是否包含端点。
3. 特殊数值：NaN、无穷、负零、浮点精度误差、超出安全范围的整数。
4. 类型异常：字符串、空值、布尔、对象、数组作为参数。
5. 参数个数：缺参、多参、顺序颠倒。
6. 多参数的组合（判定表）：一个参数决定分支，另一个参数取边界。
7. 返回值的类型与范围；出错时抛出的异常类型与消息。
8. 函数间关系：交换律、复合还原、单调性、与朴素实现的结果一致。
9. 白盒：每个比较运算符两侧取值；每个分支；循环的零次、一次、多次。
10. 每条断言写明预期来自哪里（需求、文档或注释、行业惯例、源码推断）；对实现有疑问时按合理约定写预期并在用例名里标明，不要照抄实现。
```
