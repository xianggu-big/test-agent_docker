## 共性规律与统一防御范式

**根源只有一个**：LLM 的知识=训练语料的统计惯例（test/ 目录、REST 惯例、字段命名、JSON 合规、
通过压力），而**执行环境的真实契约每次都不同**。凡"惯例≠契约"处必失败。

**防御范式（本系统已实现的三层）**：
1. **契约显式化**（事前）：环境布局/字段名来源/状态码归属/输出格式全部写进提示词纪律；
2. **确定性闸**（事中）：静态闸/collect-only/表达式 ast 闸/宽容解析——AI 的假设在进考场前被
   确定性代码校验或改写，零 LLM 成本；
3. **真执行+标定**（事后）：容器真执行+变异标定+注入缺陷差集——"看起来能用"与"真能用"的
   最终裁判。
