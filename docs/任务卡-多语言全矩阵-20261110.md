## 3. 关键设计约束（跨语言一致性的前提）

1. **路线与语言解耦**（已在 routes.py 加 observation 字段）：C4 契约路线的前置条件必须从 `lang_eq python` 改为"服务可启动 + 暴露 HTTP"，语言只决定后端（TestClient/httptest/RestAssured/supertest/Laravel）；
2. **结果 schema 统一**：每条语言的执行结果必须转成既有 pytest 风格文本（js/go/java/php adapter 已做），禁止各写一套解析；
3. **治理一致性核对表**（本卡核心产出）：每语言 5 项逐格核对——expected_basis 落库？归因三分类？证人冻结？审计台账？报告双闸？**这张表是"治理不变量"的直接证据**；
4. **诚实标注"不适用"**：HTML 列的 C1-C6 不是"缺"而是"不适用"（前端无进程内调用），矩阵里必须区分——这是论文诚实性的细节。

## 5. 降级线（诚实预案）

若中期前无法全绿，按以下顺序保底：
1. **保阶段 0 + 阶段 1**（统一层 + Go 补全）= 6~7.5 天，可宣称"两语言全能力 + 四语言单元级"；
2. 次选保"每语言 C1+C2+C3"（单元+覆盖+回灌）= 每语言 1~1.5 天，可宣称"六语言覆盖与回灌全通，契约/场景/变异为 Python+Go 双语言"；
3. 矩阵里未完成格如实标"未验证"，**绝不在论文里写成已完成**。

## 6. 坑预判

1. **外部工具许可与稳定性**：Stryker/PIT/Infection/gremlins 版本漂移——钉版本进镜像（与 mutmut 同纪律）；
2. **契约路线的服务启动**：L2 依赖服务能起来（端口/健康检查超时已配）；Go/PHP 的启动方式各不同，需在 routes 前置条件里加"启动方式探测"；
3. **假绿的诱惑**：某语言"能跑但 0 用例"= 假绿（687 教训）。验收必须要求"用例数 > 0 且至少 1 条断言执行"；
4. **不要与任务卡-B/H 并行**（同动 llm_client），本卡主要动 adapters/skills，可与 B/H 并行但需避开同文件。
