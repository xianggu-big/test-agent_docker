## 2. 写作纪律（每章开工前重读）

1. **数字唯一来源**：实验数字只从 docs/链路方法测试文档.md 的 D8 聚合表与 benchmarks/results/ 结果文件取；开题阶段"预研口径"已过，正文可用实测数字，但每处数字写完回到源表核对一遍。
2. **引用纪律**：只引 literature-map.md §8 已核验条目（含 2026-10-29 借鉴清单核验行）；任何凭记忆的 arXiv 编号/DOI 写之前必须重新核验。
3. **口径**：四级=应用对象层级，论文主语=黑盒白盒方法族，Agent=载体；防造假语义（证人冻结/数字确定性/预算熔断）是设计原则不是实现细节，升格到 §4.5 单独成节。
4. **L3/L4 与 E6-E8**：先写设计意图与预期验证方式（标【P2/P3 实现后回填】），实现跑数后补实测——不虚构。
5. **审稿流程**：每章草稿完成 → academic-paper-reviewer 技能审一轮 → 修订 → 用户过目。
